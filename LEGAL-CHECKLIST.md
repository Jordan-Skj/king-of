# Liste indispensable avant la mise en ligne commerciale

Le code limite les données demandées et ajoute les pages nécessaires, mais aucune page ne peut rendre une activité automatiquement conforme. Complète les points suivants avec les informations réelles de KING OFF 6J BUSINESS.

## Informations de l’entreprise

- [ ] nom complet du responsable de publication ;
- [ ] adresse physique complète ;
- [ ] e-mail professionnel consulté régulièrement ;
- [ ] statut juridique et numéros applicables (RCCM, ID.NAT., NIF ou équivalent) ;
- [ ] contact pour les réclamations.

Ces éléments doivent remplacer les crochets dans `mentions-legales.html`.

## Vente réelle

- [ ] moyens de paiement réellement acceptés ;
- [ ] moment du paiement ;
- [ ] zones de livraison, coûts et délais ;
- [ ] indication claire sur les taxes et sur l’inclusion ou non des frais de livraison ;
- [ ] règles de retrait ;
- [ ] garanties effectivement proposées ;
- [ ] procédure d’échange, retour ou réclamation ;
- [ ] manière de confirmer la disponibilité et de remettre une preuve de vente si nécessaire.

Ces règles doivent être écrites dans `conditions-generales.html` et appliquées dans la réalité.

## Données personnelles

- [ ] nom/adresse/e-mail du responsable du traitement ;
- [ ] durée de conservation des échanges WhatsApp ;
- [ ] personnes autorisées à accéder aux demandes ;
- [ ] procédure pour répondre aux demandes d’accès, correction, opposition ou suppression ;
- [ ] vérification auprès de l’autorité compétente de la nécessité d’une déclaration ou d’une autorisation préalable pour les traitements envisagés, conformément au Code du numérique RDC ;
- [ ] analyse des obligations du Code du numérique RDC avant d’utiliser WhatsApp, Cloudflare ou tout hébergement pouvant traiter des données hors RDC ;
- [ ] configuration de Turnstile et de la clé secrète dans Cloudflare si le formulaire est conservé.

## Images, contenu et transparence

- [ ] remplacer les illustrations locales par tes photos ou des images avec licence commerciale ;
- [ ] vérifier chaque prix et chaque modèle avant publication ;
- [ ] ne pas promettre une disponibilité, une garantie ou une livraison que tu ne peux pas confirmer ;
- [ ] ne pas ajouter de faux avis, compteurs ou remises artificielles.
